# 음폐수 MEC 수소 물질수지 대시보드

음폐수 10톤/일을 기준으로 다음 공정의 유량, COD 부하, 수소 생성량과 정제 후 생산량을 계산하는 단일 HTML 대시보드입니다.

```text
음폐수 → 3상분리기 → 산발효 → 세라믹 멤브레인 → MEC → 수소 정제
```

## 실행

`index.html`을 웹 브라우저에서 열면 됩니다. 별도 서버나 라이브러리가 필요하지 않습니다.

## 계산식

- 원수 COD 부하(kg-COD/day) = 원수 유량(m³/day) × COD 농도(kg/m³)
- 각 단계 COD = 전 단계 COD × 해당 단계 COD 회수율 또는 보존율
- MEC 제거 COD = MEC 유입 COD × MEC COD 제거율
- 원수소(kg-H₂/day) = MEC 제거 COD × 0.125 kg-H₂/kg-COD × 실제 수소수율
- 정제수소(kg-H₂/day) = 원수소 × 정제 수소 회수율
- 수소 부피(Nm³/day) = 수소 질량 × 11.126 Nm³/kg-H₂
- 제품가스 부피 = 정제수소 부피 ÷ 제품 수소 순도

## 초기 입력값

| 항목 | 초기값 |
|---|---:|
| 음폐수 투입량 | 10 t/day ≈ 10 m³/day |
| 원수 COD | 100 kg/m³ (100,000 mg/L) |
| 3상분리 액상 회수율 | 92% |
| 3상분리 COD 회수율 | 85% |
| 산발효 COD 보존율 | 95% |
| 멤브레인 투과수 회수율 | 85% |
| 멤브레인 COD 투과율 | 90% |
| MEC COD 제거율 | 80% |
| MEC 수소수율 / 이론값 | 65% |
| 정제 수소 회수율 | 90% |
| 제품 수소 순도 | 99.9% |

## 주의

초기값은 개념설계용 가정입니다. 실제 설계에는 CODCr, TS/VS, 용존성 COD, VFA 전환율, 막 회수율, Coulombic efficiency, cathodic hydrogen recovery, 가스 조성 및 정제설비 성능의 실측값을 적용해야 합니다.
